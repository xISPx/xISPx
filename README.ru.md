## 🚀 Обо мне

- 🔧 Собираю **прототип смарт-часов** на ESP32-S3 с сенсорным AMOLED-экраном 2.06" (Waveshare)
- 🖥️ Проектирую интерфейсы на **LVGL** — круглые экраны, циферблаты, двойная буферизация
- 🕹️ Сделал **Игротеку** — 50 браузерных мини-игр на чистом JS, без сборки
- ⚙️ Автоматизирую всё, до чего дотягиваюсь, на **Bash** и **Python**
- 📡 PlatformIO + Arduino, периферия I²C/QSPI, PMU, IMU, аудиокодеки
